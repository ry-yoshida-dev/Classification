# svc

## Overview

Parameters for scikit-learn `SVC`. The default pipeline standardizes features, and the processor exposes margins rather than probabilities.

## Components

| Component | Description |
|-----------|-------------|
| [parameter.py](./parameter.py) | `SVCParameters`. |
| [kernel.py](./kernel.py) | `SVCKernel` enum. |
| [gamma.py](./gamma.py) | `SVCGamma` enum of automatic kernel coefficient rules. |
